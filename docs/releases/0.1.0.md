DSH Project Desktop 0.1.0 — 应用更新接入版 / Application updates edition

独立的项目桌面：项目创建与欢迎页、多项目独立窗口、多 Profile、官方恢复与安全模式，以及资源、记忆、任务、技能和 MCP 管理。

本次重新发布保持版本号 0.1.0，增加应用级更新检查。欢迎页、帮助/托盘菜单和官方版本浮层共用一套更新流程；检查我们自己的 GitHub Releases，确认后下载并校验安装包。默认启动 60 秒后检查，此后每 6 小时检查，同一新版只后台通知一次。已经安装旧 0.1.0 的用户请手动下载覆盖一次，之后可获得更新提示。

An independent desktop for project creation, isolated project windows, multiple Profiles, recovery/safe mode, and resources, memory, tasks, skills and MCP. This republished 0.1.0 adds application-wide update checks using our GitHub Releases and the official update UI and lifecycle. Checks start after 60 seconds and repeat every six hours; each new version is announced once. Users of the previous 0.1.0 must download and install this edition manually once.

- macOS：Universal DMG，支持 Intel 和 Apple Silicon。打开 DMG 后将应用放入 Applications；更新时替换原应用。当前为 ad-hoc 签名，未进行 Developer ID 签名或公证，Gatekeeper 可能阻止首次启动。
- Windows x64：提供 NSIS 安装程序及便携 ZIP。应用内更新下载安装程序；便携用户也可从此页下载 ZIP 后手动替换。当前未进行 Authenticode 签名，可能显示 SmartScreen 提示。
- 更新整套固定组合：DSH Desktop 2.0.11 / Harness 0.1.5-rc.2 及固定 Project 插件。仅支持 stable；没有 Linux 包或静默安装。

macOS downloads are Universal (Intel + Apple Silicon), ad-hoc signed and not notarized; Gatekeeper may block the first launch. Windows x64 installers and portable ZIPs are unsigned and may trigger SmartScreen. Updates replace the complete pinned runtime combination. Only stable is supported; Linux packages and silent installation are not provided.

源码、恢复、安全模式和双 Host 检查通过后才打包；同一 DMG 在 Apple Silicon / Intel CI 启动验证，Windows 便携应用在构建目录外启动。更新弹窗使用真实官方窗口验收；测试中的目标文件选择与安装器交接使用隔离替身，Windows 安装向导、升级和卸载仍需人工验证。

Packaging requires source, recovery, safe-mode and dual-Host checks. The same DMG is launch-tested on Apple Silicon and Intel CI; the Windows portable application is launched outside the checkout. Update dialogs are exercised as real official windows, while test download destinations and installer handoff use isolated substitutes. Windows installer UI, upgrade and uninstall still require manual verification.
