# 0.1.12 — 缩小 Windows x64 安装包 / Smaller Windows x64 packages

## 中文

- Windows x64 打包时跳过依赖包声明为仅支持 ARM64 的可选模块，避免将无法在 x64 运行的 LibreOffice Kit 和 uv ARM64 二进制文件装入安装包。
- Windows 便携包的安装自检确认 x64 模块存在、ARM64 模块缺席。
- macOS 继续提供与当前 dsh-desktop 发行方式一致的 Universal DMG，同时支持 Intel 和 Apple Silicon。

运行时仍固定为 Desktop 2.0.15 / Harness 0.1.7-rc.2。本版的打包体积和原生启动验收结果以发布工作流为准。macOS 使用 ad-hoc 签名且未公证；Windows 安装包未签名。

## English

- Windows x64 packaging skips optional dependencies declared for ARM64 only, removing LibreOffice Kit and uv binaries that cannot run on x64.
- The portable package check confirms the x64 modules are present and the ARM64 modules are absent.
- macOS keeps the current dsh-desktop style Universal DMG for Intel and Apple Silicon.

The pinned runtime remains Desktop 2.0.15 / Harness 0.1.7-rc.2. Package sizes and native launch verification are determined by the release workflow. The macOS app is ad-hoc signed without notarization; Windows packages are unsigned.
