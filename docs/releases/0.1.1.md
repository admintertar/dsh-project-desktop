DSH Project Desktop 0.1.1 — 静态更新清单修复版 / Static update feed fix

此次重新发布保持版本号 0.1.1，修复 GitHub 匿名 API 限流导致“未能获取更新信息”的问题。应用直接读取随 Release 发布的 `update.json`，版本检查和安装包校验均不再调用 GitHub REST API；网络仍跟随系统代理。失败提示区分连接失败、超时和 HTTP 错误。

This republished 0.1.1 fixes update checks failing when a shared IP exhausts GitHub's anonymous API quota. Both version checks and installer verification now read the static `update.json` release asset, without GitHub REST API calls or user tokens. Requests still use the system network/proxy. Failure dialogs distinguish connection failures, timeouts and HTTP errors.

**已经安装 0.1.1 的用户需手动下载并覆盖安装一次；同版本重发不会触发升级提示。** 旧版客户端仍使用原 API，限流期间也请手动下载。本次之后发布流程会自动生成清单，并真实验证匿名访问。

**If you already have 0.1.1, download and install this edition manually once; equal versions do not trigger an upgrade prompt.** Older clients still use the API and may also need a manual download while rate-limited. Future releases automatically generate the manifest and verify anonymous access.

- macOS 的“检查更新”移至 **DSH Project Desktop** 应用名称菜单，位于“服务”之前，直接复用官方菜单模板。
- 移除设置页额外的版本号与更新浮层，保留原有终端、诊断及重启操作。
- 欢迎页、托盘和后台更新检查继续共用应用级更新服务及官方更新弹窗。

- On macOS, **Check for Updates** now appears in the **DSH Project Desktop** application-name menu, before Services, using the official menu template.
- Settings no longer adds a version label or update popover. Terminal, diagnostics and restart actions remain available.
- Welcome, tray and background checks continue to share the application-wide update service and official update dialogs.

macOS 提供 Universal DMG（Intel / Apple Silicon），使用 ad-hoc 签名、未公证；Windows x64 提供未签名的 NSIS 安装程序和便携 ZIP。固定运行时仍为 Desktop stable 2.0.11 / Harness 0.1.5-rc.2 及原固定 Project 插件。自动发布须通过两平台源码与原生更新窗口检查、打包启动检查及同一 DMG 的 Intel 验收；Windows 安装向导、升级和卸载交互仍需人工验证。

macOS ships a Universal DMG (Intel / Apple Silicon), ad-hoc signed without notarization. Windows x64 ships unsigned NSIS and portable ZIP packages. The pinned Desktop stable 2.0.11 / Harness 0.1.5-rc.2 and Project plugin remain unchanged. Publication requires platform source and native update UI checks, packaged launch checks and Intel verification of the same DMG. Windows installer UI, upgrade and uninstall still require manual verification.
