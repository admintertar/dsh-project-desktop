# 0.2.0 — 直接接入官方 Desktop / Direct official Desktop integration

## 中文

- DSH Project Desktop 壳直接使用 DeepSeek 官方 Harness/Desktop **0.2.0-rc.2**，不再依赖 Anywhere Labs 社区版 dsh-desktop。
- 保留欢迎、创建/打开项目、多窗口与项目菜单；项目资源、任务、记忆、技能及 MCP 由 Project 插件提供。
- 多项目共享 DeepSeek 登录账号；模型 API Key、Host 与浏览器分区继续按项目隔离。
- 更新入口复用官方侧栏与更新弹窗，下载我们自己的发行文件；区分关闭页面和关闭当前项目。
- 修复深色侧栏、底部白条、插件页面窗口拖动及聊天重复工作区入口。
- CI 从固定官方源码与依赖锁构建，分别验证 macOS arm64、macOS x64、Windows x64 的原生运行时与安装产物。

### 安装与限制

这是我们壳的正式版 **0.2.0**；内置官方上游版本仍为 **0.2.0-rc.2**。

macOS 请按芯片选择 arm64（Apple Silicon）或 x64（Intel）DMG；Windows 提供安装器和便携 ZIP。**0.1.x 请从本页手动下载安装**，原 universal 更新清单不能自动处理本版的分架构安装包。

**旧社区 Stable 项目数据尚未迁移。** 本版会拒绝接管旧 Home 并保留原文件；仍需访问旧会话的用户应保留 0.1.11 和原数据备份，等待迁移工具。请先使用新建项目验证，不删除旧数据。应用身份和默认数据目录沿用现有产品，安装本版会替换同名应用。

macOS 使用 ad-hoc 签名，未做 Apple 公证；Windows 安装包未签名。官方网页登录页的手动打开按钮可能唤起已安装的官方客户端。

## English

- DSH Project Desktop now directly uses the official DeepSeek Harness/Desktop **0.2.0-rc.2**, removing the Anywhere Labs community Desktop dependency.
- The Shell owns welcome, project creation/opening, multiple windows and menus. The Project plugin provides resources, tasks, memory, skills and MCP.
- DeepSeek account sign-in is shared across projects. Model API keys, Hosts and browser partitions remain isolated.
- Updates reuse the official sidebar indicator and dialog with our own release artifacts. Page close and project close are grouped separately.
- Fixes cover dark sidebar appearance, the bottom strip, plugin-page window dragging and the redundant chat workspace entry.
- CI builds pinned official sources and locked dependencies, validating native runtimes and relocated packages on macOS arm64, macOS x64 and Windows x64.

### Installation and limitations

This is Shell **0.2.0 Stable**, bundling official upstream **0.2.0-rc.2**.

Choose the arm64 DMG for Apple Silicon or x64 DMG for Intel. Windows includes an installer and portable ZIP. **Upgrade from 0.1.x manually using this release page**; its universal-only update contract cannot select the new per-architecture packages.

**Legacy community Stable project data migration is not available yet.** This version rejects legacy Homes while preserving their files. Keep 0.1.11 and a data backup if you need old conversations, and wait for the migration tool. Validate with a newly created project first. The application identity and default data directory are retained; installation replaces the application of the same name.

macOS uses ad-hoc signing without Apple notarization. Windows packages are unsigned. The manual-open button on the official web sign-in page may launch an installed official client.
