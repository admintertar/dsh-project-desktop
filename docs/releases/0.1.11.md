# 0.1.11 — 修复桌面设置样式、Project 侧栏快捷键与目录选择器 / Desktop settings and Project runtime fixes

## 中文

本版修复升级到 Desktop 2.0.15 后实际操作才会触发的兼容问题：

- **恢复桌面设置页样式**：Shell 构建不再丢弃自有 `settings.css`，桌面设置的行布局、开关、选择框和插件市场卡片恢复正常样式；
- **修复 Project 任务侧栏按钮**：补齐官方 ExpandButton 所需的快捷键注入，避免点击任务页右侧边栏时出现 `useShortcuts is not a function`；
- **补齐 macOS 目录选择器 IPC**：注册 `dsh-desktop:native-directory-picker`，沿用主窗口同源与主 frame 校验，并在窗口关闭时移除 handler；
- Project 插件固定提交更新为 `e1130d82bd3db791fb4f30d01aaf25af5ccf7f7f`。

### 验证

- Desktop 2.0.15 / Harness 0.1.7-rc.2；
- Shell `yarn check` 通过：153 个应用测试、7 个恢复测试、1 个安全模式测试及 Host 冒烟；
- Project 插件 `yarn typecheck` 和 `yarn test` 通过：308 个测试；
- 隔离 Electron 演示窗口确认桌面设置页样式已恢复，任务页侧栏不再复现快捷键异常。

## English

This release fixes compatibility issues that only appeared after upgrading to Desktop 2.0.15:

- **Restores Desktop settings styling**: the Shell build now retains its own `settings.css`, restoring the settings rows, switches, selects and plugin-market cards;
- **Fixes the Project task-sidebar toggle**: the official ExpandButton shortcut injection is provided, avoiding `useShortcuts is not a function` when opening the task sidebar;
- **Adds the macOS directory-picker IPC handler**: `dsh-desktop:native-directory-picker` now uses the existing same-origin/main-frame checks and is removed when the window closes;
- Pins the Project plugin to `e1130d82bd3db791fb4f30d01aaf25af5ccf7f7f`.

### Verification

- Desktop 2.0.15 / Harness 0.1.7-rc.2;
- Shell `yarn check` passed: 153 application tests, 7 recovery tests, 1 safe-mode test and Host smoke checks;
- Project plugin `yarn typecheck` and `yarn test` passed: 308 tests;
- An isolated Electron preview confirmed the Desktop settings styling and task-sidebar path.
